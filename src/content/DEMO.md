# Demo content

This file marks the template's demo site: the pages About, Team, Blog and Contact, the demo
blog, the contact form, the "Call to action" shared section and their views, routes, texts
and images. The demo specs in `tests/e2e/demo/` run only while this file exists.

Start a project with `pnpm demo:remove`: it deletes the demo (this file included), keeps a
minimal home page and the infrastructure, and checks that everything still compiles
(docs/CUSTOMIZING.md § Remove the demo site).
